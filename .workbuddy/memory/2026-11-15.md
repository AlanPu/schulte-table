## 修掉的原版 bug（Kotlin 版同样存在）
1. **汉字错位**：`CHINESE_NUMBERS[number - 1]` 使 1 显示「零」、36 显示「三十五」。
   数组第 0 项是「零」，应取 `[number]`。
2. **字母溢出**：6×6=36 格但 `fromCharCode(65+n-1)` 只到 Z，27~36 会变成 `[ \ ] ^ _ \``。
   改为 A–Z 后接 a–j。

## 布局坑（重要经验）
- 用 `getBoundingClientRect` 算棋盘尺寸 → 棋盘宽度**反过来撑开** grid 容器
  （`min-width:auto`），resize 后尺寸永远**滞后一轮**，且手机尺寸下纵向溢出。
- 正解：`container-type: size` + `--side: min(100cqw, 100cqh)`，字号用
  `--cellpx` × 系数（按模式与字数分档）全部交给 CSS，JS 只同步 `--n` / `--gap`。
- 横屏还需放开 `.stage { max-width: 860px }` → 1180px，否则两列布局下棋盘被挤窄。

## PWA 缓存策略
- 初版 cache-first 导致改代码后用户永远拿旧版（调试时被坑：汉字修复"没生效"）。
- 改为 **stale-while-revalidate** + `sw.js` / `index.html` 不缓存（nginx 层配合）。
- 发布不兼容大改时 bump `sw.js` 的 `VERSION` 触发整体重建。

## 验证方式（可复用）
- 本机无 Docker/Playwright → 用 **Edge headless + CDP**（`--remote-debugging-port=9222`）
  经 `WebSocket` 驱动：`Emulation.setDeviceMetricsOverride` 模拟 iPad 竖/横屏、
  `Network.emulateNetworkConditions offline` 验证离线、`Runtime.evaluate` 点格子跑完整流程。
- 关键断言：格子宽高相等、`scrollHeight <= innerHeight`、暂停时计时停住、
  离线 reload 后格子数仍正确。
- ⚠️ 测前必须 `serviceWorker.getRegistrations().unregister()` + `caches.delete()`，
  否则测的是旧缓存。

## 群晖要「镜像包」而非「源码包」（2026-11-15 复盘）
用户拿 `-docker.tar.gz` 在 Container Manager「映像 → 导入」里报**格式无效**——因为那是源码包。
群晖区分两类文件：**映像导入只吃 `docker save` 产物**；源码要走「项目 → 新增 → compose」。

本机**没有 Docker**，于是写了 `web/tools/build_image_tar.py` 手工组装镜像包：
1. 走 DoH 代理（ClashX `127.0.0.1:7890`）拉 `nginx:alpine` 的 linux/amd64 manifest
   - ⚠️ 沙箱默认代理 `127.0.0.1:54758` 不放行 Docker Hub；`auth.docker.io` 直连超时
   - ⚠️ **zsh 不对未加引号变量分词**：`P="-x http://..."` 后 `curl $P` 会把整串当一个参数 → 空响应
2. 逐层 gzip 解压、校验 `sha256(raw) == config.rootfs.diff_ids[i]`
3. 追加一层：站点 → `usr/share/nginx/html/`，`nginx.conf` → `etc/nginx/conf.d/default.conf`
4. 输出**经典 docker save 格式**：`manifest.json` + `<sha256(config)>.json` + `<sha>/layer.tar`
5. 自检 25 项（层摘要、config 文件名与内容 sha 一致、overlay 后 `index.html` 不是 nginx 欢迎页、
   `usr/sbin/nginx` 是 x86-64 ELF machine=62）

用户群晖架构 = **amd64**（从其 `elec-score` 镜像 config 的 `architecture` 字段确认）。

⚠️ 群晖创建容器时**容器端口必须填 80**（镜像内 nginx 监听 80），本地端口 14174。
